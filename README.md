# TechNest
想创建一个自己的技术社区,实现技术的记录、分享、交友、吐槽之类的一个社区


### 个人技术社区搭建全流程

**简介**:
搭建个人博客的主要原因是因为想要将web开发的整条链路打通
经历一下web开发的每一个流程,让自己能够更好的进行web开发工作
也想将自己想要记录的内容放到自己的网站当中去
以上就是搭建自己个人博客的心理路程





#### 开发流程总览

**需求与设计阶段**

1. 需求定义
2. 设计阶段（产出 Figma 设计稿,或者直接AI生成实际的网页）

**技术准备阶段**

3. 技术方案设计（含技术选型、数据库设计、接口定义）
4. 环境准备（开发环境、数据库、第三方服务申请）

**开发与测试阶段**

5. 开发阶段（编码 + 自测）
6. 测试阶段（功能测试、兼容性测试、性能测试）

**部署与上线阶段**

7. 部署执行（打包、发布到生产环境）
8. 上线验证（冒烟测试）

**交付与运维阶段**

9. 交付与验收（提交源码与文档，客户确认）
10. 后期维护（Bug 修复、性能监控、小版本迭代）





### 1.需求定义

个人技术社区搭建背景:
在做完一个react项目后,想要使用项目中的经验去搭建一个自己的个人技术社区
搭建个人博客想把web开发的整条链路打通,经历一下web开发的每一个流程,让自己能够更好的进行web开发工作
搭建个人博客想把自己想要记录的内容放到自己的网站当中去,更好的整理自己的工作或者生活内容
希望大家可以在博客园中分享自己,在当今交友困难的时代,我希望能做到一个通过分享技术,或者分享生活,来慢节奏交友的博客园

功能需求模块:

| 模块名称         | 核心功能                              | 职责描述                   |
| :--------------- | :------------------------------------ | :------------------------- |
| **用户认证模块** | 注册、登录、用户信息                  | 身份验证与权限控制         |
| **个人中心模块** | 我的文章、我的点赞/收藏、个人资料编辑 | 用户自我管理               |
| **内容管理模块** | 博客编辑、展示、状态、审核、管理      | 文章的生命周期管理         |
| **用户交互模块** | 评论、点赞、收藏、关注、私信          | 用户间的行为互动           |
| **数据分析模块** | 运营总览看板、个人数据看板            | 数据聚合、统计与可视化展示 |

#### 1.1.用户认证模块

##### 用户注册与登录

##### 前置条件
- 用户进行注册前，需勾选同意《用户协议》及《隐私政策》，未勾选时注册按钮不可用。

系统支持以下三种注册途径：***手机号注册、邮箱注册、第三方社交账号注册***。

##### 手机号注册

- **步骤**：
  1. 用户输入手机号 → 点击“获取验证码” → 系统发送 6 位数字验证码至该手机号。
  2. 用户填写验证码 → 验证通过后，自动进入下一步。
  3. 用户填写**昵称**和**密码** → 点击“注册”完成。

- **规则**：
  - 手机号需为有效号码，且**在全平台唯一**（已被注册或绑定的手机号不可再次使用）。
  - 昵称不可为空，长度 2-12 个字符，支持中英文、数字、下划线。
  - 密码长度 8-20 位，至少包含字母和数字。
  - 密码用于手机号换绑后的备用登录方式。

- **错误提示**：
  - 手机号已被注册/绑定 → “该手机号已被注册，请直接登录”
  - 验证码错误/过期 → “验证码错误” / “验证码已过期，请重新获取”
  - 昵称已被占用 → “该昵称已被占用，请更换一个”
  - 密码不合规 → “密码长度需为 8-20 位，且包含字母和数字”


##### 邮箱注册

- **步骤**：
  1. 用户输入邮箱 → 点击“获取验证码” → 系统发送 6 位数字验证码至该邮箱。
  2. 用户填写验证码 → 验证通过后，自动进入下一步。
  3. 用户填写**昵称**和**密码** → 点击“注册”完成。

- **规则**：
  - 邮箱需为有效格式，且**在全平台唯一**（已被注册或绑定的邮箱不可再次使用）。
  - 昵称和密码规则同手机号注册。

- **错误提示**：
  - 邮箱已被注册/绑定 → “该邮箱已被注册，请直接登录”
  - 验证码错误/过期 → “验证码错误” / “验证码已过期，请重新获取”
  - 昵称已被占用 → “该昵称已被占用，请更换一个”
  - 密码不合规 → “密码长度需为 8-20 位，且包含字母和数字”


##### 第三方社交账号注册

- **支持平台**：微信、QQ、支付宝、GitHub、Google
- **步骤**：
  1. 用户点击第三方图标 → 跳转至第三方授权页面。
  2. 用户确认授权后，系统获取第三方账号的 `openid`、昵称、头像等信息。
  3. 首次授权时，系统自动创建账号，使用第三方昵称作为默认昵称（如重名则自动追加随机后缀）。

- **规则**：
  - 一个第三方账号（`openid`/`unionid`）**在全平台唯一**，不可同时绑定多个本地账号。
  - 创建账号时，如果第三方返回的昵称与已有用户重名，系统自动在昵称后追加随机后缀（如 `张三_wechat_a1b2`）。
  - 用户注册成功后，可在个人中心修改昵称、绑定手机号或邮箱。
  - **无需额外设置密码**，后续登录直接使用第三方授权即可。

- **错误提示**：
  - 第三方授权失败 → “授权失败，请稍后重试”
  - 第三方账号已被绑定 → “该第三方账号已绑定其他账号，请直接登录”


##### 用户登录

系统支持以下三种登录途径：手机号登录、邮箱登录、第三方社交账号登录。

##### 手机号登录

- **方式一：验证码登录（推荐）**
  - 用户输入手机号 → 点击“获取验证码” → 填写验证码 → 点击登录。
  - 适用于日常登录场景。

- **方式二：密码登录**
  - 用户输入手机号 + 密码 → 点击登录。
  - 适用于手机号已更换、无法接收验证码的备用场景。

- **规则**：
  - 验证码 5 分钟内有效。
  - 密码错误超过 5 次，账号将锁定 15 分钟。

- **错误提示**：
  - 手机号未注册 → “该手机号尚未注册，请先完成注册”
  - 验证码错误/过期 → “验证码错误” / “验证码已过期，请重新获取”
  - 密码错误 → “密码错误，您还有 X 次尝试机会”
  - 账号已锁定 → “账号已被锁定，请 15 分钟后重试”


##### 邮箱登录

- **方式**：用户输入邮箱 + 密码 → 点击登录。

- **规则**：
  - 密码错误超过 5 次，账号将锁定 15 分钟。

- **错误提示**：
  - 邮箱未注册 → “该邮箱尚未注册，请先完成注册”
  - 密码错误 → “密码错误，您还有 X 次尝试机会”
  - 账号已锁定 → “账号已被锁定，请 15 分钟后重试”


##### 第三方社交账号登录

- **支持平台**：微信、QQ、支付宝、GitHub、Google
- **步骤**：
  1. 用户点击第三方图标 → 跳转至第三方授权页面。
  2. 用户确认授权后，系统校验该第三方账号是否已绑定本地账号。
     - 已绑定 → 直接登录成功。
     - 未绑定 → 自动创建新账号并登录（流程同第三方注册）。

- **规则**：
  - 一个第三方账号只能绑定一个本地账号。
  - 登录成功后，系统返回登录态（如 JWT token）。

- **错误提示**：
  - 第三方授权失败 → “授权失败，请稍后重试”
  - 第三方账号已绑定其他账号 → “该第三方账号已绑定其他账号，请使用对应账号登录”


##### 账号唯一性规则（汇总）

| 凭证类型       | 唯一性要求                 | 说明                                               |
| :------------- | :------------------------- | :------------------------------------------------- |
| **手机号**     | 全平台唯一                 | 已被任一账号注册或绑定的手机号，不可再次注册或绑定 |
| **邮箱**       | 全平台唯一                 | 已被任一账号注册或绑定的邮箱，不可再次注册或绑定   |
| **第三方账号** | 全平台唯一                 | 已被任一账号绑定的第三方账号，不可再次绑定其他账号 |
| **昵称**       | 允许重复（或唯一，需确认） | 建议允许重复，系统通过 `user_id` 区分用户身份      |

**用户角色**

### 1.2. 个人中心模块

个人中心是用户管理自身内容、行为和账户信息的核心入口。模块分为以下五个子功能：


#### 1.2.1. 博客管理

用户对自己发布的博客进行统一管理。

- **功能列表**：
  - **查看我的博客**：以列表形式展示自己发布的所有博客，支持分页加载。
  - **删除博客**：删除指定的博客。删除后该博客不再公开可见，且不可恢复（需二次确认）。
  - **编辑博客**：进入博客编辑页，修改标题、正文、分类、标签等信息后重新发布。已发布的博客修改后是否需要重新审核，由后台审核规则决定。
  - **置顶博客**：将指定博客置顶到个人主页顶部，最多支持 3 篇置顶（数量可配置）。置顶博客在列表中优先展示。
  - **更改排序**：支持按创建时间、更新时间、浏览量等方式对博客列表进行排序。

- **规则说明**：
  - 已删除的博客不占用用户博客配额。
  - 置顶操作仅影响个人主页的展示顺序，不影响全站列表的排序逻辑。


#### 1.2.2. 点赞管理

用户回顾和取消自己点赞过的博客。

- **功能列表**：
  - **查看点赞列表**：展示用户所有点赞过的博客，按点赞时间倒序排列。
  - **取消点赞**：点击后可取消对该博客的点赞，点赞数相应减 1。

- **规则说明**：
  - 取消点赞后，该博客从点赞列表中移除。
  - 支持再次点赞（点赞数重新加 1）。


#### 1.2.3. 收藏管理

用户回顾和取消自己收藏过的博客。

- **功能列表**：
  - **查看收藏列表**：展示用户所有收藏过的博客，按收藏时间倒序排列。
  - **取消收藏**：点击后可取消对该博客的收藏。

- **规则说明**：
  - 取消收藏后，该博客从收藏列表中移除。


#### 1.2.4. VIP 信息

展示用户的 VIP 会员状态及权益信息。

- **已开通 VIP 时**：
  - 显示当前 VIP 套餐名称（如“年度会员”）。
  - 显示成为 VIP 的日期及到期日期。
  - 当 VIP 距离到期不足 7 天时，在页面顶部显示续费提醒横幅。
  - 提供 **续费** 按钮，跳转至续费流程。

- **未开通 VIP 时**：
  - 显示 VIP 套餐列表（包含各套餐的权益对比和价格）。
  - 提供 **开通 VIP** 按钮，跳转至支付流程。

- **套餐内容示例（可根据实际调整）**：
  | 权益项           | 普通用户 | VIP 用户 |
  | :--------------- | :------: | :------: |
  | 查看付费文章     |    ❌     |    ✅     |
  | 下载附件/源码    |    ❌     |    ✅     |
  | 上传文件大小限制 |   10MB   |  100MB   |
  | 博客置顶数       |   0 篇   |   3 篇   |


#### 1.2.5. 个人资料管理

用户管理自己的基本资料和账户信息。

- **可编辑字段**：
  | 字段   | 说明                                                    |
  | :----- | :------------------------------------------------------ |
  | 头像   | 支持上传图片，自动裁剪为 1:1 比例，建议尺寸 200x200px   |
  | 昵称   | 2-12 个字符，支持中英文、数字、下划线（全平台允许重名） |
  | 生日   | 日期选择器，格式 YYYY-MM-DD                             |
  | 职业   | 自由文本输入，如“前端工程师”                            |
  | 居住地 | 省/市 二级联动选择器                                    |
  | 手机号 | 需验证原手机号后方可修改（换绑流程见账号安全）          |
  | 邮箱   | 需验证原邮箱后方可修改（换绑流程见账号安全）            |

- **账号注销**：
  - 提供 **注销账号** 按钮。
  - 点击后触发二次确认弹窗，用户需阅读注销须知并再次确认。
  - 确认后进入**冻结期**（如 7 天），期间用户可登录并撤销注销申请。
  - 冻结期结束后，账号及关联数据（博客、评论、点赞、收藏等）将被**永久删除且不可恢复**。

### 1.3. 内容管理模块


#### 1.3.1. 博客列表页

主页展示所有已审核通过的博客。

- **排序**：支持按浏览量、更新时间、创建时间、点赞数、收藏数、评论数排序（正序/倒序）。默认按创建时间倒序。
- **检索**：支持按关键字（标题/作者昵称）搜索，支持按时间段筛选。
- **交互**：点击博客卡片进入详情页。


#### 1.3.2. 博客详情页

- 展示博客完整内容（标题、正文、作者、发布时间等）。
- 显示浏览量、点赞数、收藏数、评论数。
- 登录用户可点赞、收藏、评论。


#### 1.3.3. 博客一览管理页（仅管理员）

管理员管理全站博客。

- **展示**：显示全站所有博客，含状态（待审核 / 已打回 / 已通过 / 草稿）。
- **排序**：同 1.3.1。
- **检索**：支持按标题、作者昵称、作者 ID、时间段、状态检索（多条件组合，AND 关系）。
- **交互**：
  - 点击标题/“详情” → 跳转前台详情页。
  - 仅“待审核”的博客显示“审核”按钮 → 进入审核页面（1.3.4）。


#### 1.3.4. 审核页面（仅管理员）

- **展示**：博客完整内容及当前状态（仅“待审核”可进入）。
- **操作**：
  - 审核状态（必选）：已通过 / 已打回 / 待审核
  - 审核批语（可选）：限 500 字
  - 点击“提交”完成审核
- **规则**：
  - 审核后作者可在个人中心查看结果及批语。
  - 已打回的博客，作者修改后可重新提交（状态变为“待审核”）。
  - 审核操作需记录日志（操作人、时间、原状态、目标状态、批语）。
