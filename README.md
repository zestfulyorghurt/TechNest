### 1.需求定义

个人技术社区搭建背景:
在做完一个react项目后,想要使用项目中的经验去搭建一个自己的个人技术社区
搭建个人博客想把web开发的整条链路打通,经历一下web开发的每一个流程,让自己能够更好的进行web开发工作
搭建个人博客想把自己想要记录的内容放到自己的网站当中去,更好的整理自己的工作或者生活内容
希望大家可以在博客园中分享自己,在当今交友困难的时代,我希望能做到一个通过分享技术,或者分享生活,来慢节奏交友的博客园

功能需求模块:

#### 1.1.用户认证模块

##### **用户注册**

想定有以下的三种注册途径:***手机号注册***,***第三方社交账号注册***,***邮箱注册***

- ***手机号注册***
  手机号注册一般只需要使用手机号加短信验证码的方式进行注册就可以了
- ***第三方社交账号注册(微信,qq,支付宝,github,google)***
  完全和第三方应用账号进行绑定
- ***邮箱注册***
  需要用户填写自己的邮箱
  用户查看邮箱的验证码以及填写自己想定的密码之后才能进行注册

**用户登录**

想定有以下的山中登录途径:***手机号登录***,***第三方社交账号登录***,***邮箱登录***

- ***手机号一键登录***
  用户填写手机号,获取验证码,填写验证码,完成登录
- ***第三方社交账号登录(微信,qq,支付宝,github,google)***
  完全和第三方应用账号进行绑定
- ***邮箱登录***
  需要用户填写自己的邮箱
  用户查看邮箱的验证码以及填写自己想定的密码之后才能进行登录

#### 1.2.个人中心模块

主要分为***博客管理***、***点赞管理***、***收藏管理***、***VIP信息***、***个人资料管理***

***博客管理:***
对自己的博客进行管理
删除自己的博客,更新自己的博客,将自己的博客置顶,给自己的博客更换排序

***点赞管理:***
回顾自己点赞过的博客,可以取消点赞

***收藏管理:***
回顾自己收藏过的博客,可以取消收藏

***VIP信息:***
如果已经是VIP,显示VIP的具体套餐内容,显示何时成为的VIP,以及VIP何时到期,VIP续约等问题
如果不是VIP,显示VIP的具体套餐内容

***个人资料管理:***
对个人信息进行编辑
头像，昵称，生日，职业，居住地，手机号，邮箱
可以选择注销账号
